6.1 變數：給資料一個名字

變數（Variable）是「有名字的盒子」，可以存放數字或文字，也能隨時修改。

Scratch
將 [分數] 設為 0     ← 初始化
將 [分數] 增加 1     ← 修改
顯示 [分數]          ← 讀取
MakeCode
let score = 0
score += 1
basic.showNumber(score)
變數監視器：Scratch 的變數可以勾選「顯示」，在舞台上即時看數值變化——這是除錯利器。

6.3 Worked Example：計數問答機

範例
目標：連續答對加分，答錯歸零
Scratch：
  當 ⚑ 被點擊
  將 [連續答對] 設為 0
  重複無限次
    詢問「7 × 8 = ?」並等待
    如果 <回答 = 56> 那麼
      將 [連續答對] 增加 1
      說出「答對了！」1 秒
    否則
      將 [連續答對] 設為 0
      說出「再接再厲」1 秒

對照 MakeCode：
  on button A pressed
    if 答對 then score += 1 else score = 0
數學連結：「隨機 + 迴圈 + 變數」就能做出練習題生成器——程式設計是練習數學的最佳載具。

6.4 練習

  1. 做一個「每按一次空白鍵 +5」的計數器。
  2. 用邏輯積木：當「分數＞10 且 生命＞0」時說「GOOD」。
  3. 把分數用字串連接顯示：「分數：」＋分數。
