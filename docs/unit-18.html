18.1 從螢幕到世界

積木程式的終極舞台是真實世界：MakeCode 控制 Micro:bit 的感測器、LED 與馬達，讓學生看到「程式真的能控制東西」。

Scratch（螢幕）→MakeCode（積木）→Micro:bit（真實硬體）
STEAM 連結：這正是「STEAM 的 E（工程）」——程式 + 硬體 = 作品。可與 STEAM × Micro:bit 站互補。

18.2 MakeCode 感測專案

範例
傾斜偵測（水平儀）：
forever
  let x = input.acceleration(Dimension.X)
  if x > 300 then
    show icon（右傾）
  else if x < -300 then
    show icon（左傾）
  else
    show icon（水平）

光線警示：
forever
  if input.lightLevel() < 40 then
    show string "太暗了"
    play tone

18.4 整合課程設計

範例
「聲控燈」跨工具課（2 堂）：
第1堂（Scratch）：做「麥克風偵測→燈泡圖案」的螢幕版
第2堂（MakeCode）：同樣邏輯搬到 Micro:bit，控制真實 LED

學生體驗：
  1. 先玩邏輯（螢幕）
  2. 再見真章（硬體）——「原來程式能開燈！」
教學原則：先在螢幕上把邏輯搞懂，再搬到硬體加實體感——一次只加一個新變因。

18.5 練習

  1. 用 MakeCode 做一個「光線太暗會叫」的專案。
  2. 設計一堂「先 Scratch 後 MakeCode」的整合課。
看完這單元你應該能說出：
  • 說明積木程式與實體裝置的串聯方式。
  • 用 MakeCode + Micro:bit 做感測專案。
  • 規劃 Scratch 與硬體的整合課程。
