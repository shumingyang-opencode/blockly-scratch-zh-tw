12.1 同一顆引擎，不同的舞台

Blockly 家族的每個工具都共用積木邏輯，但舞台不同：

工具舞台你能做什麼
MakeCodeMicro:bit 板子LED、感測器、無線電、機器人
App InventorAndroid 手機App、感測器、地圖
Blockly Games瀏覽器小遊戲學序列/迴圈/條件
Scratch 3舞台動畫、遊戲、故事
核心觀點：學會 MakeCode 的積木 = 會操作 Micro:bit；而「事件、迴圈、變數」這些概念跟 Scratch 完全一樣。

12.2 MakeCode 與 Micro:bit 快速上手

範例
目標：按按鈕顯示表情
on button A pressed
  show icon 😀
on button B pressed
  show icon 😢
on shake
  show string "哦不！"

燒錄：MakeCode 網頁 → 下載 .hex → 拖進板子

12.3 從積木到「真的裝置」

  • Scratch 的「當按鍵按下」→ MakeCode 的「on button pressed」。
  • Scratch 的「變數」→ MakeCode 的「let 變數」。
  • Scratch 的「碰到」→ MakeCode 的「加速度 > 門檻」。
教學價值：從螢幕到實體，學生會發現「程式真的能控制世界」——這是 STEAM 整合的橋（見單元 18）。

12.4 Worked Example：計步器（MakeCode）

範例
變數 steps = 0
on shake
  change steps by 1
  show number steps
on button A pressed
  set steps to 0      ← 重設
on button B pressed
  show number steps   ← 查看總步數

延伸：加 LED 動畫慶祝（每 100 步播音樂）。

動手：在 MakeCode 做一個「按 A 重設、按 B 查看」的計步器，並燒錄到 Micro:bit。
