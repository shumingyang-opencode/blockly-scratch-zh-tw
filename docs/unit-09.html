9.1 遊戲的骨架

幾乎所有積木遊戲都有同一套遊戲迴圈：

移動→碰撞判斷→更新分數/生命→結束判定→重來

9.2 碰撞偵測

積木偵測什麼
碰到 ( ) ?碰到某精靈/顏色/邊緣
距離 ( )與某角色的距離
按下 ( ) ?鍵盤或滑鼠輸入
範例
當 ⚑ 被點擊
重複無限次
  如果 <碰到 [蘋果] ? > 那麼
    將 [分數] 增加 1
    廣播「吃到蘋果」
    隨機位置出現新蘋果

9.3 得分、生命與結束

範例
變數：分數、生命
重複無限次
  如果 <碰到 [炸彈] ? > 那麼
    將 [生命] 增加 -1
    播放聲音 [爆炸]
  如果 <生命 = 0> 那麼
    說出「遊戲結束，分數：」+ 分數
    停止 [全部]

9.4 Worked Example：接蘋果遊戲

範例
角色：籃子（玩家）、蘋果、炸彈
籃子：
  當 ⚑ 被點擊
  重複無限次
    定位到 x:(滑鼠x) y:(-160)   ← 跟著滑鼠走
蘋果：
  當 ⚑ 被點擊
  重複無限次
    移到隨機x, y:180
    重複直到 碰到籃子 或 y<-180
      將 y 改變 -3
    如果 碰到籃子: 分數+1
    否則: 生命-1
炸彈：同蘋果，但碰到「分數-2」
結束：生命=0 → Game Over
除錯重點：遊戲最容易出錯的是「碰撞沒反應」——先用「碰到？說出結果」積木確認偵測生效。

9.5 練習

  1. 為你的遊戲加「困難度」：分數越高，蘋果掉越快。
  2. 設計一個「分數 × 生命」的結束畫面。
看完這單元你應該能說出：
  • 用碰撞偵測實作得分與生命。
  • 設計遊戲迴圈（移動/碰撞/更新/結束）。
  • 完成一款可玩的遊戲專案。
