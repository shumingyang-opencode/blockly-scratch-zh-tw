4.1 積木的接頭

積木像拼圖，有三種接頭：

接頭形狀作用例子
卡榫（hat）圓頂腳本的起點（事件）當 ⚑ 被點擊
堆疊（stack）上下凹凸依序執行的指令移動 10 步
嵌入（insert）缺口/圓洞作為「值」填入重複 (隨機 1~10) 次
為什麼接頭形狀有意義：圓頭只能填進圓洞——這在語法層面就防止了「把句子當數字」這類錯誤。積木程式天生防呆。

4.2 腳本：積木的串接

腳本（Script）是一串上下堆疊的積木，從上到下依序執行。一個專案可以有很多腳本，各自用不同事件啟動。

Scratch
當 ⚑ 被點擊        ← 事件（啟動）
說出「早安」2 秒   ← 第1行
移動 50 步         ← 第2行
等待 1 秒          ← 第3行
移動 50 步         ← 第4行

4.3 依序執行（Sequence）

  • 程式從上到下執行，一行做完才做下一行。
  • 改順序 = 改行為：把「移動」放「說出」前面，結果不同。
  • 這是「序列」概念——所有程式語言的基礎。

4.4 Worked Example：雙工具「跳舞」腳本

範例
Scratch（角色跳舞）：
當 ⚑ 被點擊
重複 4 次
  移動 30 步
  等待 0.5 秒
  移動 -30 步
  等待 0.5 秒
  換下一個造型

MakeCode（LED 眨眨眼）：
on start
  forever
    plot x 2 y 2        ← 亮
    pause 200 ms
    unplot x 2 y 2      ← 滅
    pause 200 ms
對照重點：兩個程式都是「重複 + 動作 + 等待」——概念完全一樣，只是舞台不同。

4.5 練習

  1. 找出你腳本裡的三種接頭各一個。
  2. 把「說早安」與「移動」對調，預測行為會變什麼。
  3. 在 MakeCode 做出「LED 眨 3 次」。
看完這單元你應該能說出：
  • 說明積木的接頭類型與拼法。
  • 解釋腳本如何啟動與依序執行。
  • 完成雙工具的第一支腳本。
