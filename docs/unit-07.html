7.1 舞台座標系統

Scratch 舞台是 480×360 的座標空間，中心是 (0, 0)：

座標
左上 (-240, 180) ───── 右上 (240, 180)
        │    中心 (0,0)    │
左下 (-240, -180) ───── 右下 (240, -180)
積木功能
定位到 x:( ) y:( )把精靈放到指定座標
移動 10 步朝目前方向移動
面朝 ( ) 度設定方向
滑行到 x:( ) y:( )平滑移動

7.2 造型：角色的「換裝」

  • 一個精靈可以有多個造型（Costume）。
  • 連續切換造型 = 動畫（走路、飛翔、跳舞）。
  • 「下一個造型」積木 + 迴圈 = 最簡單的動畫。
範例
當 ⚑ 被點擊
重複無限次
  移動 10 步
  下一個造型        ← 換一張圖
  等待 0.2 秒

7.3 聲音與特效

積木功能
播放聲音播放音效
開始/停止所有聲音音樂控制
圖形特效色彩、魚眼、旋轉等視覺特效
顯示/隱藏角色可見性

7.4 Worked Example：跳舞的角色

範例
目標：角色跟著音樂跳舞
當 ⚑ 被點擊
重複無限次
  面朝 90 度       ← 向右
  移動 40 步
  下一個造型
  播放鼓聲 1 下
  等待 0.3 秒
  面朝 -90 度      ← 向左
  移動 40 步
  下一個造型
  播放鼓聲 2 下
  等待 0.3 秒

動手：做一個會來回走動並切換造型的角色，加上一段音樂。

看完這單元你應該能說出：
  • 說明舞台座標系統與精靈定位。
  • 用造型切換做出動作效果。
  • 完成角色動畫實作。
